research

I work on understanding how neural networks learn and reason: the geometry of memory in RNNs, multi-step reasoning in LLMs, learning in physical systems. Lately that means LLM security, agent simulations, in-context learning for science, and sampling-based planning for robotics.

academic projects
  • Coherent Ising machines. Research with NTT's Coherent Ising Machine group on optical hardware for hard combinatorial optimization: each laser pulse in a fiber ring acts as a spin, and measurement-feedback couples the pulses until the light settles into a low-energy solution. NTT Research, 2020
  • Exceptional points in non-Hermitian quantum systems. Studied exceptional points and exotic properties of large non-Hermitian systems with an algorithm I developed. with Fabrizio Minganti, RIKEN
  • Noisy mean-field annealing. Tuned NMFA for NP-hard combinatorial problems using ideas from quantum thermodynamics. with Neill Lambert, Clemens Gneiting, Ken Funo, RIKEN
  • Quantum overlapping tomography. Built a tomography module using perfect hash families, based on Frank Wilczek's paper, and measured entanglement quality on IBM machines. with Rudy Raymond, IBM Research; Qiskit Asia Camp, Japan
  • PyFroid. A Pandas plugin that gets 100x speedups on some operations through lazy evaluation. with Karthik Ramachandra, MSR India
  • Speech event segmentation. Better segmentation metrics via quantile analysis of intersyllable durations, and point-process models of syllable events. with Neville Ryant, LDC
  • Ontology-aware medical concept extraction. BiLSTM-CRF and transformers with UMLS embeddings for EHR entity recognition. with Lyle Ungar, Penn
  • Neural network potentials. ResNet-based potentials for copper thermal expansion, validated in LAMMPS. with Paris Perdikaris, Penn
  • Quantum and classical key exchange protocols. Cryptology research at the ACM Summer School, one of the top 50 undergrads selected nationwide. ISI Calcutta
  • Computational geometry library. C++ implementations of convex hulls, polygon triangulation and point visibility. with Tathagata Ray, BITS Pilani
  • MPI parallel code optimization. PETSc-based aerofoil sensitivity analysis on hybrid GPU-CPU systems. with N. Anil, BITS Pilani
  • Data envelopment analysis for student performance. DEA-based efficiency analysis of student input factors. with Srinivasa Raju, BITS Pilani
